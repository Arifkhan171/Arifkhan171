## 👨‍💻 About Me

I am an AI Engineer based in Pakistan with a BSCS degree from the University of Loralai and over 3 years of hands-on experience building AI systems. My work spans the full spectrum of modern AI — from deep learning and medical image analysis to multi-agent architectures and production agentic pipelines.

I build complete systems, not just models. Every project I ship is end-to-end — from data ingestion and validation to database storage, API integration, and human-in-the-loop review dashboards.

I am currently open to **remote AI Engineer** and **Agentic AI Engineer** roles.

**Core expertise:**
- 🤖 Agentic AI — LangChain, LangGraph, LangSmith, Multi-Agent Systems
- 🧠 Deep Learning — TensorFlow, Keras, Medical Image Analysis
- 🔍 RAG Pipelines — Hybrid Search, GraphRAG, CRAG, ColBERT, ChromaDB
- 🗄️ Backend & Databases — SQLAlchemy, PostgreSQL, SQLite, Google APIs

### 📊 Agentic GPA Calculation System
> *End-to-End LangGraph Pipeline — Tech Lead*

A fully autonomous GPA system that reads student mark sheets directly from Google Drive, validates every data point against 22 edge case rules using Pydantic v2, calculates GPA and CGPA using the HEC Pakistan formula, writes results to a relational database, and generates student transcripts — managed through a Streamlit Human-in-the-Loop dashboard.

Built and managed as Tech Lead across a 3-engineer team with full GitHub branch workflow, PR reviews, and sequential pipeline integration.

### 🎓 University AI Chatbot — Multi-Agent RAG System
> *Production System — In Development*

A production-grade university chatbot on a 5-specialist-agent LangGraph architecture. Uses hybrid search combining ChromaDB and BM25 via Reciprocal Rank Fusion, cross-encoder reranking, GraphRAG, Corrective RAG, and parent-child retrieval. Planned multilingual support in Urdu, Pashto, and English.
